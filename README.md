No conviene usar SELECT * porque trae un montón de columnas que capaz ni precisás, y eso hace más lenta la consulta. Además, si después le agregan columnas a la tabla, te puede cambiar el resultado y romper cosas. También puede mostrar datos sensibles sin necesidad. Mejor pedir solo las columnas que necesitás.
Los alias son importantes para las personas no tecnicas debido a que permiten generalizar datos tecnicos a lenguaje mas accesible para cualquier persona, de esa forma interpetar los resultados se vuelve mas accesible en general.En el ejemplo de total_amount as monto_total, una persona de finanzas que es buena pero no entiende ingles, veria limitado su trabajo a noser, que ese documento se renombre con as al español
